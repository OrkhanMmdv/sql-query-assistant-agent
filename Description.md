# System Description

## AI or Agent-Based Approach

The system will be implemented as a simple intelligent agent. The agent will receive user input, analyze the request, determine which tool should be used, generate an SQL query, validate it, execute it on a local SQLite database, and return the result in a readable format.

The workflow of the system:

```text id="xfmt41"
User Request
↓
Agent Analysis
↓
SQL Generation
↓
Query Validation
↓
Database Execution
↓
Formatted Output
```

## Tools That Will Be Used in the System

* SQL generation tool
* SQL validation tool
* SQLite database execution tool
* Result formatting tool
* Input validation tool

## Preliminary List of Programming Concepts Required

* Python functions
* Classes and objects
* Modules and imports
* Conditional statements
* Lists and dictionaries
* String processing
* SQLite database integration
* Exception handling
* User input/output
* Unit testing
* Git and GitHub version control
